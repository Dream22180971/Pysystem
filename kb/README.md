# 内部知识库（Markdown）

本目录用于存放“内部流程 / 系统使用”类文档，后端会按 `app.kb.path` 扫描并建立索引，提供：

- 文档列表：`GET /api/kb/docs`
- 关键词检索：`GET /api/kb/search?q=...`
- 读取文档：`GET /api/kb/doc?path=...`
- 重建索引（管理员）：`POST /api/kb/resync`

## 目录建议

- `系统使用/`：页面功能说明、字段解释、常见操作步骤
- `SOP/`：采购入库、库存盘点、退货、交接班等标准流程
- `常见报错/`：401/403、数据为空、导入失败、打印异常等

## 编写规范（推荐）

- 标题用 `#` / `##` 分层
- 每个流程尽量包含：**适用范围**、**步骤**、**注意事项**、**升级路径**
- 截图可放在同目录下（后端目前只索引 `.md` 文本，图片不参与检索）
